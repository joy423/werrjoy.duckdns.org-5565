🎮 So importierst du ein Modell

1. Webstudio öffnen

Starte deinen Paper-Server und öffne das verbundene Webstudio.

2. Datei importieren

Wähle deine BME-TXT-Datei im Importbereich aus.

3. Spielcode erstellen

Erzeuge einen neuen Code und kopiere den vollständigen Minecraft-Befehl.

4. In Minecraft einlösen

Füge /bme apply DEINCODE mit deinem echten Code in den Chat ein.
